# Вкладыш-диорама: генератор развёртки

**[Открыть страницу в браузере →](https://pimplebattletoad.github.io/diobox/)**

Страница работает целиком в браузере: вводите размеры коробки, кладёте картинку —
получаете лист 1:1 в PNG и PDF для печати. Ничего не отправляется на сервер,
картинка остаётся у вас. Локальная версия (Python) умеет то же самое и описана ниже.

---

Небольшая программа, которая строит плоскую выкройку вкладыша в коробку
(задник + две боковины + пол + потолок), раскладывает на ней ваш рисунок
и сохраняет:

* `*_sheet.png` — лист 1:1, 300 dpi (универсальный файл, годится для типографии);
* `*_sheet.pdf` — то же в PDF, страница в масштабе 1:1 (A4/A3/A2 либо
  автоматически разложено на несколько листов с наложением);
* `*_assembled.png` — превью собранной диорамы, чтобы увидеть результат
  до печати.

Зависимости: Python 3 + Pillow + numpy (в поставке DSH уже есть).

---

## Быстрый старт

```bat
gen.cmd --box 200x150x100 --art foto.jpg --out out/diorama
```

`--box` — **внутренние** размеры коробки, мм: ширина × глубина × высота.
Коробка закрывается со всех сторон: рисунок раскладывается по заднику,
боковинам, полу и потолку так, что при взгляде спереди видна целая картинка
(объёмная раскладка, см. «Как это устроено»).

Файлы появятся в `out\`: `diorama_sheet.png`, `diorama_sheet.pdf`,
`diorama_assembled.png`.

Проверка без картинки (демо-пейзаж):

```bat
gen.cmd --box 200x150x100 --demo --out out/demo
```

## Страница в браузере

Если не хочется набирать параметры в командной строке, запустите `gen.cmd`
без аргументов — поднимется локальная страница и откроется браузер
(`http://127.0.0.1:8765/`). Всё считается тем же кодом, что и в CLI, только
параметры вводятся мышкой:

* **картинка** — перетащить в рамку, выбрать файл или вставить из буфера
  (`Ctrl+V`); кнопка «Демо-пейзаж» подставляет тестовый рисунок;
* **размеры коробки** — Ш × Г × В в мм и «Тонкая настройка»: зазор, клапаны,
  вылет, поле, dpi, формат бумаги, раскладка картинки (объёмная / плоская),
  раскладка листа (авто / боковины на полу / боковины на заднике),
  галочка «закрыть сверху потолком», «пустая развёртка» (примерка без картинки),
  оформление боковин и пола;
* рамка на картинке показывает, **что именно попадёт внутрь коробки** — её
  можно тянуть мышкой; в объёмной раскладке рисунок продолжается на боковины,
  пол и потолок;
* кнопка «Сделать выкройку» выдаёт PNG 1:1, PDF для печати и превью собранной
  диорамы; файлы складываются в `out/web/<дата-время>/`, рядом кнопка
  «Показать в папке».

Полезное:

* если выкройка не влезает на A4 целиком, страница предложит взять A3 —
  одним нажатием, без ручного пересчёта;
* страница показывает, сколько будет листов и какого они размера, ещё до
  генерации — по строке под размерами;
* с телефона в той же Wi-Fi: `python ui_server.py --host 0.0.0.0`
  (адрес вида `http://192.168.x.x:8765/` напечатается при запуске);
* всё локально: страница не ходит в интернет и ничего никуда не отправляет.

Если поменять размеры после генерации, блок «Готово» гаснет и появляется
пометка «размеры изменились» — старая выкройка остаётся на месте, но видно,
что её надо пересобрать.

Служебные файлы:

| Файл | Зачем |
|---|---|
| `ui_server.py` | локальный сервер страницы (без внешних зависимостей) |
| `ui.html` | сама страница: разметка, стили и вся логика |
| `tools/probe_api.py` | проверка API: своя картинка → PNG + PDF |
| `tools/cdp_shot.mjs` | скриншоты страницы в headless Chrome (нужен Chrome) |
| `tools/cdp_eval.mjs` | быстрый прогон JS на странице (`probe_*.js`) |

## Основные параметры

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `--box ШxГxВ` | `200x150x100` | внутренние размеры коробки, мм |
| `--art файл` | — | рисунок (jpg/png/webp/tiff, EXIF-поворот учитывается) |
| `--out префикс` | `out/diorama` | куда и под каким именем писать |
| `--dpi` | `300` | разрешение листа |
| `--fit` | `0.5` | зазор вкладыша от стенок коробки, мм на сторону |
| `--wall-h` | высота коробки − 2 | высота стенок вкладыша, мм |
| `--tab` | `12` | глубина клеевого клапана, мм (`0` — без клапанов) |
| `--bleed` | `3` | вылет рисунка под рез, мм |
| `--margin` | `12` | поле листа, мм |
| `--side` | `wrap` | оформление боковин в плоской раскладке: `wrap` / `blur` / `solid` / `none` |
| `--floor-mode` | `blur` | оформление пола в плоской раскладке: `blur` / `solid` / `none` |
| `--fill` | `box` | `box` — объёмная раскладка на все панели, `flat` — старый вариант (задник + продолжение края) |
| `--depth-k` | `1.8` | насколько далеко «камера» при объёмной раскладке (больше — меньше искажение) |
| `--no-ceiling` | выкл. | не печатать потолок: вкладыш останется открытым сверху |
| `--blank` | выкл. | пустая развёртка: только контур, сгибы и клапаны — для примерки без расхода краски |
| `--layout` | `auto` | раскладка листа: `auto` — самая компактная, `cross` — боковины на полу, `back` — боковины на заднике |
| `--art-mode` | `cover` | `cover` — заполнить задник с обрезкой, `contain` — вписать целиком |
| `--focus X,Y` | `0.5,0.5` | какая часть рисунка остаётся в кадре (0..1) |
| `--paper` | `auto` | формат PDF: `a1`, `a2`, `a3`, `a4`, `none` (страница = выкройка) |
| `--labels` | выкл. | подписать панели прямо на рисунке (для пробной печати) |
| `--no-marks` | выкл. | только рисунок, без линий реза/сгиба |
| `--no-preview` | выкл. | не делать превью диорамы |

Примеры:

```bat
:: рисунок «съезжает» — сдвинуть кадр вправо и вверх
gen.cmd --box 200x150x100 --art foto.jpg --focus 0.65,0.4

:: боковины — размытое продолжение вместо растянутого края
gen.cmd --box 250x180x120 --art foto.jpg --side blur --floor-mode solid

:: без клапанов, печать одним листом A2
gen.cmd --box 200x150x100 --art foto.jpg --tab 0 --paper a2
```

## Печать

1. Печатать **в масштабе 100 %** («реальный размер», без «вписать в страницу»).
   На листе есть линейка 50 мм — после печати приложите линейку и проверьте.
2. Бумага: 200–250 г/м², лучше матовая. Глянец даёт блики внутри коробки.
3. Если выкройка не влезла на A4, PDF автоматически режется на листы
   с наложением 10 мм и метками совмещения — склейте их встык по рисунку,
   затем режьте контур.
4. Для типографии берите PNG: он ровно в масштабе (300 dpi) и без потерь.

Внизу листа, слева от штампа, есть **легенда**:

* сплошная чёрная линия — **резать**;
* штриховая серая — **сгиб**;
* бежевая плашка `КЛЕЙ` — **клапан под склейку**.

## Пустая развёртка (примерка)

Прежде чем тратить краску, соберите макет из **пустой развёртки** — это та же
выкройка, но без картинки: только контур, сгибы, клапаны, подписи панелей с
размерами и легенда. Занимает секунду и почти не расходует картридж.

```bat
gen.cmd --blank --box 200x150x100 --out out/fit
```

На странице — галочка «пустая развёртка — только линии». Соберите макет,
вставьте в коробку: если стенки жмут или потолок не садится, поправьте
`--fit` / `--wall-h` и повторите. Готовую выкройку печатайте уже с картинкой.

## Сборка

1. Вырезать по сплошному чёрному контуру.
2. Если есть клапаны — сделать два разреза по вертикальным линиям у задника
   (они уже нарисованы как линии реза).
3. Продавить сгибы по штриховым линиям: тупой нож/спица + линейка, чтобы
   картон не треснул.
4. Согнуть все стенки **вверх** (к себе, на 90°) — рисунок окажется внутри.
   Потолок сгибается последним: он ложится сверху и упирается в переднюю
   стенку коробки, закрывая щель над задником.
5. Клапаны — их три пары:
   * **боковые у задника** приклеивают стенки к заднику;
   * **верхние у стенок** (`КЛЕЙ` вдоль верхней кромки) отгибаются на потолок
     и приклеиваются к нему **сверху** — изнутри картинка остаётся целой,
     а потолок держится по всей длине стенок.
   Клеить можно и внутрь, но тогда 12 мм клапана закроют край рисунка.
   Не нужны совсем — `--tab 0`.
6. Вставить вкладыш в коробку рисунком внутрь.
7. Смотреть на диораму спереди, на уровне середины коробки: объёмная
   раскладка рассчитана именно на эту точку, сбоку картинка «расползается».

## Как это устроено

Развёртка — крест: пол `W×D` в центре, задник `W×H` сверху, потолок `W×D`
над задником, боковины `H×D` слева и справа, плюс клеевые клапаны. Всё в
миллиметрах, лист строится с учётом вылета под рез.

Потолок приклеен к верхней кромке задника: при сгибе он накрывает коробку
сверху, поэтому сверху не остаётся белой щели. Если он не нужен — `--no-ceiling`
(или снять галочку на странице).

Стенки по умолчанию идут во всю высоту коробки минус 2 мм: 1 мм — толщина
картона и погрешность резки, ещё 1 мм — чтобы потолок ушёл под верхние
клапаны коробки.

### Раскладка листа (`--layout`)

Боковины можно крепить двумя способами, и от этого сильно зависит размер
листа:

* `cross` — боковины приклеены к **полу**, в стороны уходит высота стенок:
  лист `(W + 2(H + T)) × (H + 2D)`;
* `back` — боковины приклеены к **заднику**, в стороны уходит глубина:
  лист `(W + 2D) × (H + 2D)`.

`auto` (по умолчанию) считает оба варианта и берёт тот, у которого короче
длинная сторона листа — именно она решает, влезет ли выкройка на A4 или A3.
Например, для 200 × 150 × 100 выгоднее `cross` (443 × 438), а для высокой
80 × 40 × 100 — `back` (181 × 218 против 323 × 218, то есть один лист A4
вместо четырёх).

В раскладке `back` клапаны стоят сверху и снизу стенок: верхние
приклеиваются на потолок, нижние уходят под пол.

### Объёмная раскладка (`--fill box`, по умолчанию)

Рисунок трактуется как **вид внутрь коробки** из точки перед ней. Каждая
панель — не отдельная картинка, а трапеция внутри вашего изображения: панель
сэмплируется через проективное преобразование, поэтому на сгибах рисунок
продолжается без разрыва, а при взгляде спереди собирается в целую картинку.

Края кадра «уходят» на стенки: точка на стенке тем ближе к краю изображения,
чем ближе она к открытой стороне коробки. Коэффициент `--depth-k` задаёт,
насколько далеко воображаемая камера: 1.8 — умеренное искажение, 3–4 —
мягче, но на боковины попадает меньше рисунка. Углы и сгибы затеняются
(ambient occlusion), иначе коробка читается как плоская картинка.

Обратная сторона медали: это анаморфоза — идеально картинка видна из той
точки, для которой считалась. Смотреть нужно **спереди и примерно на уровне
середины** коробки; сбоку перспектива «расползается».

### Плоская раскладка (`--fill flat`)

Старый режим: рисунок кладётся на задник целиком (обрезка по центру), его
края растягиваются на боковины, низ — на пол, верх — на потолок. Проще и
предсказуемее, но сгибы видны как стыки, а не как продолжение сцены.

## Версия для GitHub Pages (docs/)

В папке docs/ лежит та же программа, переписанная на JavaScript (Canvas), — её и отдаёт
GitHub Pages. Точка входа docs/index.html, счёт полностью в браузере, без сервера.

* docs/js/geom.js — развёртка (панели, контур, сгибы, клапаны, выбор раскладки);
* docs/js/warp.js — проективное сэмплирование трапеций (анаморфоза);
* docs/js/art.js — раскладка картинки по панелям и затемнение у сгибов;
* docs/js/sheet.js — отрисовка листа (клапаны, подписи, линейка, легенда, штамп);
* docs/js/pdf.js — PDF с нарезкой на листы (JPEG в DCTDecode, без библиотек);
* docs/js/preview.js — превью собранной коробки;
* docs/js/demo.js — демо-пейзаж data URL (чтобы работало и с ile://);
* docs/sw.js, docs/manifest.webmanifest — офлайн-кэш и установка как приложение.

Открыть локально: любым статическим сервером, например
python -m http.server 8899 --directory docs, и зайти на http://127.0.0.1:8899/.
Двойной клик по index.html тоже работает; установка приложения и офлайн-кэш — только
по https (или localhost).
